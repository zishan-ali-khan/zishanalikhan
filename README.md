## 🚀 Featured project

### [FlatCare Tracker](https://github.com/zishan-ali-khan/flatcare-tracker)
A repair and warranty tracking system for new-build flats. It calculates each flat's 6-month free-repair deadline, flags overdue complaints, and shows everything in an Excel tracker, a Power BI dashboard and a live Streamlit app with a countdown.

**Tools:** SQL Server · Python · pandas · Streamlit · Power BI · Excel
